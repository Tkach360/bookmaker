🎲 Betting Gateway Online

API-шлюз микросервисной архитектуры ставок. Взаимодействие с backend-сервисами осуществляется асинхронно через RabbitMQ.

Доступные эндпоинты:

GETПолучить ставку
/bet/:id
Пример: /bet/1
POSTСоздать ставку
/bet
Создает новую ставку для пользователя на указанное событие. 
{
  "user_id": 1,
  "event_id": 1,
  "amount": "100.50"
}
Пример curl: 
curl -X POST http://localhost:8080/bet \
  -H "Content-Type: application/json" \
  -d '{"user_id":1, "event_id":1, "amount":"100.50"}'
GETПолучить событие
/event/:id
Пример: /event/1
Powered by Go, Gin & RabbitMQ
