🎲 Betting Gateway

Online

API-шлюз букмекерской системы. Gateway принимает HTTP-запросы и взаимодействует с backend-микросервисами через RabbitMQ.

Технологии: Go · Gin · RabbitMQ · AsyncAPI

Доступные эндпоинты

GET

Получить ставку

/bet/:id

Возвращает ставку по её идентификатору. В ответе содержатся ID ставки, ID события, сумма и пользователь.

Открыть пример: /bet/1
Пример ответа 
{
  "id": 1,
  "event_id": 1,
  "amount": "1000",
  "user": "Вячеслав"
}
POST

Создать ставку

/bet

Создаёт ставку для указанного пользователя на выбранное событие. Сумма передаётся строкой в десятичном формате.

Тело запроса — JSON 
{
  "user_id": 1,
  "event_id": 1,
  "amount": "100.50"
}
Пример запроса через curl 
curl -X POST http://localhost:8080/bet \
  -H "Content-Type: application/json" \
  -d '{"user_id":1,"event_id":1,"amount":"100.50"}'
Если событие не найдено или не принимает ставки, сервис возвращает соответствующую ошибку.
GET

Получить ставку и информацию о событии

/bet/:id/details

Возвращает ставку вместе с информацией о связанном событии, включая коэффициент и статус события.

Открыть пример: /bet/1/details
Пример ответа 
{
  "bet": {
    "id": 1,
    "event_id": 1,
    "amount": "1000",
    "user": "Вячеслав"
  },
  "event": {
    "event_id": 1,
    "coefficient": "0.6",
    "status": "open"
  }
}
GET

Получить все ставки на событие

/event/:id/bets

Возвращает список ставок, связанных с указанным событием. В ответ включаются ID события и массив ставок.

Открыть пример: /event/1/bets
Пример ответа 
{
  "event_id": 1,
  "bets": [
    {
      "id": 1,
      "event_id": 1,
      "amount": "1000",
      "user": "Вячеслав"
    },
    {
      "id": 2,
      "event_id": 1,
      "amount": "250.50",
      "user": "Анна"
    }
  ]
}
Если ставок нет, ожидаемый формат ответа содержит пустой массив: "bets": [].
