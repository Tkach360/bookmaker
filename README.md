# Сервис букмекерской конторы

Предоставляет возможности:
- корневая html страница `/`
- создание ставки на событие `POST bet/`
- получение данных ставки `GET bet/{id}`

Разделен на 3 микросервиса:
- `gateway` - шлюз
- `bets` - ставки
- `events` - события

Микросервисы общаются между собой исключительно через RabbitMQ.

## В планах
1) доделать микросервис `events`, сейчас просто заглушка
2) написать тесты
3) добавить запросы на получение событий, получение ставок на определенное событие, создание события, изменение статуса события, отмена ставки
4) сделать логику изменения статуса события
5) раз есть ставки, должны быть и те, кто их делает. Надо создать пользователей и счета
